# 🎬 كتالوج المسلسلات الكورية

كتالوج لـ 90 مسلسل كوري (أكشن، جريمة، غموض، انتقام) مع تتبع حالة المشاهدة.

## المميزات
- تعليم كل مسلسل: لم أشاهده / أشاهده الآن / شاهدته
- بحث وفلترة حسب الحالة والسنة
- إحصائيات (الكل، شاهدته، أشاهده، المتبقي)
- قائمة مشتركة تتزامن بين كل الأجهزة (Cloudflare D1)
- حماية برمز سري (EDIT_PIN)
- نسخة احتياطية واسترجاع عبر ملف JSON
- جلب البوسترات تلقائيًا من [TVmaze](https://www.tvmaze.com/)

## النشر على Cloudflare Pages
1. اربط المستودع بـ Cloudflare Pages (بدون أمر بناء، مجلد الإخراج: `/`).
2. أنشئ قاعدة بيانات D1 واربطها بالمشروع باسم `DB`.
3. أضف متغير البيئة `EDIT_PIN` بالرمز السري.
4. أعد النشر. الجدول يُنشأ تلقائيًا عند أول استخدام.
