# 🎬 كتالوج المسلسلات الكورية

كتالوج لـ 90 مسلسل كوري (أكشن، جريمة، غموض، انتقام) مع تتبع حالة المشاهدة.

## المميزات
- تعليم كل مسلسل: لم أشاهده / أشاهده الآن / شاهدته
- بحث وفلترة حسب الحالة والسنة
- إحصائيات (الكل، شاهدته، أشاهده، المتبقي)
- حفظ التقدم تلقائيًا على نفس الجهاز (localStorage)
- نسخة احتياطية واسترجاع عبر ملف JSON
- جلب البوسترات تلقائيًا من [TVmaze](https://www.tvmaze.com/)

## التشغيل
افتح `index.html` في المتصفح، أو انشره على GitHub Pages / Cloudflare Pages.
