# 🎬 مسلسلاتي — كتالوج المسلسلات الكورية

تطبيق ويب للجوال لتتبع مشاهدة 90 مسلسل كوري (أكشن، جريمة، غموض، انتقام)، بقائمة مشتركة بين أكثر من شخص.

## المميزات
- واجهة تطبيق جوال مع شريط أزرار سفلي: الكل، أشاهده، شاهدته، النشاط، حسابي
- شاشة دخول باسم المستخدم، وكل تعديل يُسجَّل باسم صاحبه ووقته
- سجل نشاط كامل يبيّن مين علّم على أي مسلسل ومتى
- قائمة واحدة مشتركة تتزامن بين كل الأجهزة (Cloudflare D1)
- رابط خاص فيه مفتاح سري (`#k=...`)، واللي ما عنده الرابط ما يقدر يفتح التطبيق
- يمكن إضافته للشاشة الرئيسية في الآيفون والأندرويد
- نبذة عن كل مسلسل مترجمة للعربي (من TVmaze) مع التقييم والقناة والتصنيف، محفوظة للكل
- نسخة احتياطية واسترجاع عبر ملف JSON
- إضافة مسلسلات جديدة مع بحث تلقائي عن البوستر والسنة
- حذف أي مسلسل، مع صفحة "المحذوفات" لاسترجاع المسلسلات الأصلية
- بوسترات تلقائية تُجلب على السيرفر مرة وحدة وتُحفظ للكل (TVmaze، صور المواسم، ويكيبيديا)، مع إمكانية تغيير البوستر يدويًا

## النشر على Cloudflare Pages
1. اربط المستودع بـ Cloudflare Pages (بدون أمر بناء).
2. اربط قاعدة بيانات D1 باسم `DB`. الجداول تُنشأ تلقائيًا.
3. أضف متغير البيئة `ACCESS_KEY` بقيمة عشوائية طويلة.
4. افتح التطبيق بالرابط: `https://<project>.pages.dev/#k=<ACCESS_KEY>`
